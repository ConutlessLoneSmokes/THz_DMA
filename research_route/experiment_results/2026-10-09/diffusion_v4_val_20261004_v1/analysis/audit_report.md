# D-033 v4 完整训练与验证核验

日期：2026-10-04。训练 `diffusion_v4_train_20261004_v1`；验证 `diffusion_v4_val_20261004_v1`。

## 1. 判断

10000 步训练与 1152 行验证完整完成。学习扩散明显优于旧原型，但在全部 12 个协议—SNR 组中均落后条件 LMMSE，逐场景 dB 配对差值的 95% bootstrap CI 均大于零。当前 v4 未通过学习增益验证，不进入独立测试。此结果仍限于 16 个验证场景、已知逐径粗中心和匹配物理先验。

## 2. 完整性与训练

- 16 场景×2 协议×6 SNR×6 方法，共 1152 行，无重复或缺组；16 个检查点与最终 CSV 一致。
- 2504 个缓存文件的哈希通过；训练/验证/数据的源码快照分别核验 63 个文件。训练和评价归档与当前对应源码一致，模型和数据依赖哈希一致。
- 768 条 Oracle/OMP/SBL/LMMSE 与旧 16 场景验证在全带 NMSE、输出 SNR、净谱效率上逐项相同。SBL 的 192 次运行全部达到停止线。
- 共 10000 步、40 次验证；最佳加权 EDM 损失 0.584919，位于第 10000 步。第 250 步为 0.893610。训练约 14.11 min。不同批次训练损失不用于判断单调收敛。
- 旧短训练仅在 4 个样本上验证，完整训练在 32 个样本上验证，不能直接比较两次最佳损失。额外固定 4 个验证场景与同一噪声重新比较：σ=3 的线性去噪 NMSE 从 0.3731 降至 0.1490，σ=10 从 0.3789 降至 0.1208，σ=80 从 0.8275 降至 0.5739。六个检查尺度的均值均改善；这项完整含噪 CSI 去噪检查不等于 DMA 后验恢复性能。
- 在此前相同两个 55 dB 验证场景，1000→10000 步后 F1/F2 全带 NMSE 从 −5.360/−6.178 改善至 −7.994/−9.484 dB。下面的主表使用全部 16 场景。

F2 学习扩散从 65 到 70 dB 的均值由 −8.834 恶化至 −8.079 dB，中位数则由 −9.920 改善至 −10.135 dB。场景 `2026100202:0` 从 −12.659 恶化至 −5.087 dB，场景 `2026100202:7` 从 −4.725 恶化至 −0.748 dB。该尾部失稳的机制尚未由消融确认，不能归因于噪声变大或训练步数不足。

## 4. 高 SNR 高斯对照偏差

高斯扩散相对完整 LMMSE 的组均值差在 70 dB 达到 F1 +0.056、F2 +0.267 dB，不能将此前两场景 55 dB 的“差小于 0.004 dB”推广到全范围。

对逐场景差异最大的两个案例重新计算同一截断协方差的解析后验均值：

| 场景/协议，70 dB | 完整 LMMSE | 截断先验解析均值 | 高斯扩散 |
|---|---:|---:|---:|
| 0 / F2 | −29.903477 | −29.199476 | −29.199529 |
| 12 / F1 | −25.498788 | −24.817494 | −24.817479 |

两者的高斯扩散与截断解析均值差均小于 0.00006 dB，最大偏差案例中的差距由阈值 10⁻⁵ 引起的协方差截断解释。尽管保留能量超过 99.995%，高 SNR 下小特征值仍能影响估计误差。本轮保留原阈值和原结果，没有重新调参；这些高斯差距不足以解释学习方法十余 dB 的劣势。

## 5. 通信与成本

55 dB 的 F1/F2 净谱效率：学习扩散 11.224/10.300，LMMSE 11.496/10.486 bit/s/Hz。学习方法在该点没有通信收益。该指标在共同频点 301.0546875 GHz 上评价并扣除训练/切换开销，未扣估计计算延迟。

本次运行全组平均求解及重构时间：学习扩散 3.710 s，高斯扩散 1.506 s，LMMSE 0.178 s。条件先验准备另记：扩散约 10.257 s/场景，LMMSE 的基构造与观测投影合计约 9.803 s。这些准备值在多个 SNR 行中重复登记，实际基构造按场景复用，不应逐行相加作为总耗时。比较限于本次机器/运行，不将跨轮墙钟变化解释为算法变化。
