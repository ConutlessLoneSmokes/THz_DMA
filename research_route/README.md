## 2. 建议阅读顺序

确定研究主线时，依次阅读总纲、公共模型、方向一和仿真规范。补充研究现状时，先查文献地图和证据矩阵，再进入对应方向文档。准备开题或论文时，从方向文档中提取“研究现状—最近邻差异—具体问题—方法—验证”链条。

```mermaid

    A[总纲与公共模型] --> B[文献地图与证据矩阵]
    B --> C[方向研究档案]
    C --> D[统一仿真与复现]
    D --> E[决策记录]
    E --> C
```

## 3. 文档中的状态标记

- **已确认决策**：由用户明确给出或接受，可作为后续工作的约束。文献证据不能代替用户选题决定。
- **原文支持**：由指定全文直接支持的事实，另与研究推断、待验证结果区分。
- **当前建议**：基于现有证据形成的研究设计，尚未完成仿真或正式选题确认。
- **待验证**：需要通过推导、实验或追加检索判断的命题。
- **停止条件**：若出现该结果，应收缩、合并或放弃相应研究点。

## 4. 更新规则

新增文献先进入证据矩阵，再修改研究现状；只有与最近邻工作比较后，才能修改创新性判断。模型或实验口径的变更先写入决策记录，再同步到方向文档和仿真规范。各方向最多保留三篇核心文献和五篇补充文献，超出的文献作为引文追踪材料，不进入主叙事。
