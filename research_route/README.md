## 3. 文档中的状态标记

- **已确认决策**：由用户明确给出或接受，可作为后续工作的约束。文献证据不能代替用户选题决定。
- **原文支持**：由指定全文直接支持的事实，另与研究推断、待验证结果区分。
- **当前建议**：基于现有证据形成的研究设计，尚未完成仿真或正式选题确认。
- **待验证**：需要通过推导、实验或追加检索判断的命题。
- **停止条件**：若出现该结果，应收缩、合并或放弃相应研究点。
