# AI Edge 赋能太赫兹 DMA/RHS 的统一仿真与复现规范

本规范保证四个方向复用同一物理模型、数据口径和结果记录方式。研究结论应能追溯到配置、代码版本、随机种子和原始指标。

## 1. 基本原则

1. 先复现直接基线，再加入新模块。
2. 用 M0–M3 管理物理因素和退化检查，不在第一组实验同时引入全部因素，也不要求先完成全部模型才检验具体假设。
3. 学习方法和传统方法使用相同观测、先验、导频能量、表面状态和测试样本。
4. 通信结论至少由一个物理或估计指标和一个链路或任务指标共同支持。
5. 训练集、验证集和测试集按场景参数或轨迹划分，避免相邻样本泄漏。
6. 所有主结果保存逐样本指标，不只保存均值。

## 2. 建议的实现目录

```text
project/
├── configs/             # 系统、信道、表面、算法和实验配置
├── src/
│   ├── channels/        # 近场、远场、混合场和时间演化
│   ├── surfaces/        # DMA/RHS 频率响应、可行映射、互耦近似
│   ├── observations/    # 导频、OFDM 和低维观测
│   ├── estimators/      # 解析、迭代、展开和黑盒基线
│   ├── controllers/     # 跟踪、MPC、图控制和任务编排
│   └── metrics/         # 统一通信、网络和任务指标
├── scripts/             # 训练、评估、绘图、固定验证和表格生成入口
├── runs/                # 每次运行的配置、日志和检查点
└── results/             # 汇总表、原始指标和最终图
```

文档不要求立即建立上述代码目录；开始实现方向一时按此结构创建，后续方向复用模块。

## 3. 配置分层

每次实验由五类配置组成：

| 配置 | 主要字段 |
|---|---|
| 系统 | 上下行、用户数、接入点数、载频、带宽、子载波和噪声 |
| 信道 | 场景尺寸、路径数、距离和角度分布、近远场规则、移动与阻挡 |
| 表面 | 单元与馈线数、射频链、谐振、损耗、调谐集合、互耦 |
| 算法 | 先验、迭代或层数、网络宽度、优化器、损失权重 |
| 实验 | 训练/测试分布、种子、样本数、基线、消融和输出路径 |

配置保存解析后的完整值。默认值也必须写入运行目录，避免未来版本改变默认参数后无法复现。

## 4. 公共模型阶梯

| 模型 | 传播 | 表面 | 目的 |
|---|---|---|---|
| M0 | 远场、窄带或频率不变 | 理想自由合并或相移 | 单元测试和算法极限检查 |
| M1 | 太赫兹 OFDM、近场或混合场 | 频率不变可行状态 | 分离球面波与带宽效应 |
| M2 | M1 | 波导衰减、谐振频响、幅相耦合 | 主物理模型 |
| M3 | M2 + 时间变化或多节点 | 有限状态、互耦近似、参数失配 | 鲁棒性和系统扩展 |

同一图中比较多个模型时，固定物理孔径、射频链、发射能量和噪声定义。改变单元数时说明固定孔径还是固定间距。

## 5. 参数范围的使用方法

参数不采用一套永久固定值。每个方向先定义参考设置，再围绕能改变结论的变量扫描。载频、带宽、孔径、距离、分子吸收和材料损耗应来自所引用模型的适用范围，不能为放大算法收益随意选择。

方向一先固定业务频段和资源栅格，扫描训练符号、导频子载波、不同配置及切换次数，再扫描分数带宽、用户距离、馈线损耗、谐振偏移和射频链；方向二扫描速度、阻塞到达过程、预测提前量、训练与切换时延；方向三扫描重叠覆盖、前传比特、交换轮数、CSI 误差和拓扑；方向四扫描特征尺寸、任务负载、链路退化、GPU 服务时间和到达率。

## 6. 数据生成与划分

### 6.1 静态信道数据

解析生成路径参数，再由统一信道和表面模块产生观测。训练样本保存随机种子和参数，不强制保存完整高维 CSI。大规模训练采用在线生成或分块缓存，减小磁盘与内存压力。

### 6.2 时序数据

先生成完整轨迹和阻挡过程，再按轨迹、布局或场景划分训练、验证和测试。一个轨迹的相邻窗口不能跨数据集。测试至少包含新轨迹和新布局两种变化。

### 6.3 网络拓扑数据

训练集随机化用户位置和邻接关系。测试分别评估训练内规模的新布局、未见拓扑和未见节点/用户数。测试模型不能访问训练时才有的全局信息。

### 6.4 任务数据

视觉数据使用官方训练/验证或标准划分。中间特征缓存与样本 ID、模型版本、切分点和量化配置绑定。无线随机性与任务样本随机性分别设置种子，以便对同一样本比较不同通信方法。

## 7. 基线公平性

### 7.1 信息条件

每个基线标注可访问的信息：真实位置、完整 CSI、局部 CSI、有效 CSI、历史窗口、全局拓扑或未来状态。使用额外信息的算法只能作为上界，不能与实际方法并列宣称改善。

### 7.2 资源条件

统一导频资源、能量、带宽、发射功率、硬件可行集合、消息比特和计算时限。若方法需要不同资源，以资源—性能曲线比较，不选择单点掩盖差异。

方向一的频率—时间资源比较必须额外记录：

- 训练 OFDM 符号数 $T$、系统子载波数 $K_{\mathrm{sys}}$ 与导频子载波数 $K_p$；固定 $B_{\mathrm w}$ 和 $\Delta f$ 时，选频只改变导频集合。
- 实际占用导频 RE；单用户规则网格为 $T K_p$，不规则映射按实际计数。少符号不能替代少导频的证明。
- 不同 DMA 配置数 $J$、实际切换次数 $N_{\mathrm{sw}}$ 和额外稳定保护。重复配置不等于没有切换；与 CP 重叠的时间不重复计费。
- 总导频能量、逐 RE 能量及接收噪声位置；主比较保留真实损耗，不逐样本归一化抹平响应差异。
- 训练占用、必要反馈、在线处理和校准成本；训练与数据状态不同时，计入新有效 CSI 的计算或补充探测。
- 真实硬件上的时间扫描与跨频估计作为主基线；频率平坦或自由逐子载波控制仅作消融/上界。

固定带宽而改变系统总子载波数时，重新计算子载波间隔、有效符号时长和 CP 开销。给出同等通信性能下的成本曲线，以及同等资源下的性能曲线。

#### 7.2.1 方向一 Stage 2 统一平台口径

- 统计独立单位是一组生成的多径场景；同一场景中的物理层级、采集协议和方法构成配对块，执行顺序按固定随机种子打乱。
- 同一采集协议内的估计器必须读取完全相同的带噪观测。完整方法允许采用不同的原生采集协议，但真值、二维 DMA、数据频段、可行状态集合、总导频 RE 和总导频能量保持一致。
- 当前 F1 为 1 配置×128 子载波，F2 为 8 配置×16 子载波，均为 128 RE；分别报告 1/8 个训练符号和 0/7 次切换，不把等 RE 写成等时延。
- 单元噪声先于 DMA 合并，输出噪声随实际权重能量变化。保留 Lorentzian 与馈线损耗，不逐协议或逐频率归一化到同一输出 SNR。
- 可分平面波—频率平坦兼容层仅用于算法极限检查；包含精确球面距离、分子吸收及频变 DMA 的目标层用于方法结论，两层不能作为竞争方案排名。
- 微带内 $0.2\lambda_c$ 间距产生的首要未建模风险是互耦，不是 OFDM ISI。ISI/ICI 由传播与前端有效记忆、CP 和状态切换决定；互耦在主方法通过后进入 M3 失配。

Stage 2-A 的传统参照另固定以下口径：

- 方法结论只使用 `thz_physical` 真值；兼容层已经在 Stage 2-0 完成接口诊断，不混入估计器排名。
- 45/55/65 dB 输入参考 SNR 共用同一个标准噪声实现并仅改变尺度；同一场景、协议和 SNR 内所有估计器读取完全相同的观测。
- 估计前按已知的逐 RF 输出对角噪声协方差白化，不对模拟合并权重逐行归一化；模板算子必须包含球面距离、分子吸收和频变 DMA。
- 30 GHz 带宽下现有距离网格采用 1 cm 步长，与 $c/B$ 名义时延分辨尺度同量级；两者同量级不能证明字典采样充分。连续真值的性能比较前必须检查最近模板相关度、离网格恢复和错误伪峰，粗网格接口结果不能代替该检查。
- 真实几何加带噪 LS 增益的 Oracle 只作 genie-aided 结构参照，不列为可部署竞争方法，也不称为所有估计器的严格统计上界。
- F1 与 F2 的估计器排名分别给出；跨协议净谱效率必须分别扣除训练符号和切换保护，不能用基础协议差异替代方法结论。

D-024 的波束中心自适应局部网格另遵循以下条件诊断规则：

- 每条路径的粗中心必须在生成连续真值和噪声前由独立固定种子确定，并随 `seeds.json` 保存。该中心是额外的观测前先验；不得由真实坐标、带噪观测、Oracle 支持或测试指标反推。
- 真值可在粗中心的预声明半功率邻域内自然连续采样，但不得人为固定在半格位置。局部相关宽度、共同步长、窗倍数、全局锚点、候选上限和边界截断规则均在运行前由配置固定。
- 同一场景的 F1/F2 使用同一连续真值和候选坐标并分别构建精确模板；55/65 dB 复用各协议的标准噪声实现。逐场景保存粗中心、真值偏移、局部宽度、候选数、真值窗覆盖和估计是否落在局部窗并集内。
- CUDA 显式字典只改变模板计算后端。首个场景必须抽取固定数量模板与 NumPy `complex128` 参考核对，并保存相对误差和归一化相关；当前验收限为相对误差不超过 $10^{-4}$、最小 $\rho^2$ 不低于 0.99999。
- 该运行标记为 `diagnostic_only`。结果只能判断给定逐径粗中心后的局部候选采样与捕获域，不能证明未知全局几何获取、正式覆盖范围或方法排名。

### 7.3 模型容量与调参

黑盒和模型驱动网络报告参数量、乘加次数、训练时间和在线时延。各主要基线使用相近的超参数搜索预算。无法完整复现的文献结果标为“重新实现”，不写成论文原值。

## 8. 公共指标

Stage 2-A 自分域评价 v2 起，同一估计结果同时保存导频域、全 128 点及 F2 未观测 112 点的阵元 CSI NMSE；各域按误差总能量除以真值总能量计算，不对各频点 NMSE 简单平均。F1 未观测域不适用，计数为 0、CSV 空值、JSON null，不能填成 0 NMSE。旧 `channel_nmse` 保留原 16 点语义，不能代表 F2 全带。保存域索引及线性/dB 值；汇总先取线性均值再转 dB，方法配对差值使用逐场景 dB 差。固定 5 场景诊断只作描述性判断，不能替代正式统计结果。

| 层次 | 指标 |
|---|---|
| 物理 | 阵列增益、带宽边缘增益、波束偏移、物理投影损失 |
| 估计 | NMSE、角度/距离/时延 RMSE、CRLB 间距、校准误差 |
| 链路 | 可达速率、有效吞吐、训练/切换比例、连续中断时长 |
| 网络 | 和速率、5% 用户速率、QoS 违约率、协调比特与轮数 |
| 任务 | 准确率/损失、传输比特、能耗、平均及 95/99 分位时延 |
| 计算 | 参数量、FLOPs 或乘加次数、显存、批量 1 推理时延、训练时长 |

有效吞吐必须扣除训练、控制和切换占用的时隙。时延分位数由逐任务样本计算，不由每批均值近似。

## 9. 统计报告

- 解析蒙特卡洛实验至少报告独立信道或轨迹样本数、均值和 95% 置信区间。
- 神经网络主结果至少使用三个独立训练种子；训练代价很高时，先用一个种子筛选，再对最终配置运行三个种子。
- 比较算法时优先使用相同测试样本的配对差值，报告效应量和置信区间。
- 大量参数扫描区分探索性结果和最终确认结果。最终图的参数和随机种子冻结。
- 只在确实执行统计检验时报告 $p$ 值；工程性能以效应大小和资源代价为主。

## 10. 必备极限与一致性检查

1. 带宽趋近零时，宽带模型应接近窄带模型。
2. 用户距离增大时，精确球面波与远场近似的差距应减小。
3. 波导损耗和互耦关闭时，M2/M3 应退化到相应简化模型。
4. 调谐集合放宽时，物理可实现结果应趋向连续上界。
5. 噪声下降且训练充分时，估计误差应接近算法偏差或 CRLB 区域。
6. 协调比特增加时，分布式结果不应系统性恶化。
7. 无排队和无限算力时，任务模型应退化为通信受限情形。
8. 各频率 DMA 矩阵退化为同一矩阵的标量倍数时，不应凭样本数声称新增空间投影维数；保留无线时延信息与重复测量的作用。
9. 检查固定状态下前端有效记忆与 CP、切换后稳定时间及符号内时变造成的残余干扰；频域模型的适用条件不应由仿真默认掩盖。

这些检查进入自动测试或固定验证脚本，不依赖人工观察曲线。

## 11. 算力预算

### 11.1 RTX 5070 路线

- 单用户、中等阵列和子载波的方向一实验；
- 千万参数以内的展开或时序模型；
- 3–4 接入点、4–8 用户的图网络；
- CIFAR 级轻量网络和缓存特征的方向四实验。

优先使用混合精度、梯度累积、在线数据生成和检查点重计算。模型选择先在缩小配置完成，再运行最终尺度。

### 11.2 2×RTX 3090 路线

两张卡优先用于独立实验并行和超参数扫描；只有模型显存单卡不足时采用分布式训练。扩大阵列和子载波时先检查前向算子的内存复杂度，避免显式构造可通过算子乘法实现的大型字典。

## 13. 论文结果审计表

提交论文前逐项确认：

- 最近邻基线已在相同信息和资源条件下比较；
- 物理可实现结果与理想上界均已报告；
- 核心物理因素、学习模块和联合变量均有消融；
- 测试包含训练分布外的物理参数或拓扑；
- 结果同时覆盖平均性能、弱用户或尾部性能；
- 在线计算与控制时限相容；
- 图表可由保存的原始指标和固定脚本重新生成；
- 失败设置和适用边界已记录在方向文档或决策记录中。
