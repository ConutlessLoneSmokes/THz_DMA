## 2. 方法与信息条件

| 方法 | 使用的信息 | 实现与结果含义 |
|---|---|---|
| 全局 LMMSE | 训练 CSI 的实值样本二阶矩 | 复用 `EmpiricalLMMSE`；不读取测试路径或粗中心 |
| MIMO `angular_omp` | 已知导频、DFT 基、预声明每接收角域行最多 3 个非零发射 DFT 系数 | 复用本地 OMP 内核与联合 LS 回代；这是角域离散适配，不是原 DMA 三维几何 OMP，也不输出可识别距离 |
| MIMO `oracle_geometry_ls` | 真实到达/离开几何，未知复增益 | 用单位增益物理模板对同一带噪观测拟合增益；模板不读取保存的真实增益。只作额外信息结构参照 |
| 全参数真值重构 | 真实几何与真实增益 | 只检查生成模型与保存参数一致性，不计入带噪方法排名 |
| 宽带全数字 DDPM/LMMSE | 相同完整 CSI 训练分布、相同选频导频 | 每个阵元独立接收，1280 个接收通道；全带/未观测频点分别评价 |
| DMA 条件 OMP/SBL/LMMSE | 观测前逐径粗中心及其预声明局部邻域 | 复用既有适配，输出 `known_pre_observation_path_centers` 标签 |
| DMA 真实几何 LS | 真实路径几何、带噪压缩观测 | 复用既有物理模板与重构，只作结构参照 |

单频 M0 信道中的距离相位与幅度可以被未知复增益吸收，接收 ULA 的相位还不能一般分离方位角与俯仰角。因此，本轮没有把读取真实几何的操作写成从观测识别全部信道参数。

DDPM 在工作站离线训练，在线在基站边缘侧根据导频输出完整 CSI。DMA 阶段再由既有可行状态码本选择数据接收状态，记录可行波束与净谱效率。数字阶段当前只记录估计与采集资源，尚无对应的数字通信链路指标。

## 3. 载频与噪声控制

步骤 2 继续使用本地可分平面波 M0，只改变载频与吸收开关；精确球面波、频率选择性和真实 DMA 响应在步骤 3–4 进入。

固定两端阵元间距为

$$
d=0.0004996540966666667\,\mathrm m=0.5\lambda_{300\,\mathrm{GHz}}.
$$

三个配置使用相同路径和离开角种子。40 GHz 对应约 $0.0667\lambda$，是理想固定孔径对照，当前 M0 不包含互耦。若按每个载频重新使用半波长间距，$f_cd$ 保持不变，会混入物理孔径变化；旧半波长设置的历史数据保留。

训练使用各自的全局复数 RMS $\rho_f$。归一化是可逆坐标变换，恢复后乘回 $\rho_f$。真正会抵消传播损耗的是跨载频重新按各自接收功率调噪声。新配置从既有干净训练集 `zhou_mimo_formal_20261009_data_v1` 固定 $\rho_{\mathrm{ref}}$，对全部载频采用

$$
\nu_{\mathrm{phys}}(s)=\frac{N_t\rho_{\mathrm{ref}}^2}{10^{s/10}},
\qquad
\nu_f(s)=\frac{\nu_{\mathrm{phys}}(s)}{\rho_f^2}.
$$

横轴 $s$ 是该固定参照的名义 SNR。实际白化观测 SNR 另存为 `actual_whitened_snr_db`；不同载频的实际值允许不同。导频矩阵、能量、观测噪声种子和后验初始化种子固定，各物理配置分别训练匹配先验。该因素实验没有测试冻结 300 GHz 模型直接迁移到 40 GHz 的分布失配。

300 GHz、约 2 m 的吸收作用在当前系数表中较弱。含/不含吸收对照用于检查相对路径损耗进入闭环，不预设显著算法收益；较长距离和吸收窗口扫描未运行。系数表的环境元数据限制保留，未替换为新的标准大气模型。

## 4. 宽带与 DMA 的共同输入噪声

步骤 3–4 复用 `diffusion_data_20261002_v1` 的物理 CSI、路径参数和独立划分。`prepare` 只建立不可覆盖的来源清单，不重生成宽带信道。改变载频、带宽、阵列或采集定义时，该入口会拒绝复用不匹配的旧缓存。

两种前端配置均使用 `snr_reference="training_element"`。以干净训练集的**平均单阵元信道功率** $\rho^2$ 定义

$$
\nu_{\mathrm{phys}}(s)=\frac{\rho^2}{10^{s/10}},
\qquad \nu(s)=10^{-s/10}.
$$

同一 SNR 点在两个前端、两种协议中有相同物理输入噪声方差，不按测试样本或各协议输出功率重标。DMA 使用原权重白化后的已知噪声；数字接收使用独立阵元噪声。两前端观测维度不同，当前固定的是方差与各自噪声种子，不声称两者读取同一逐阵元噪声实现；同一前端的估计器共享完全相同的观测。

这个横轴不同于历史 `array_input_noise_variance` 的全阵列匹配参考，也不同于 D-034/D-037 分协议匹配的输出 SNR。对训练平均功率，旧全阵列参考比单阵元参考高 $10\log_{10}(1280)\approx31.07$ dB。绘图需保留这三个定义，不能直接叠加旧曲线。

数字选频算子把 `(B,K,S,E)` 映射到 `(B,J,Kp,S,E)`。$J$ 次重复对应独立接收噪声，同一频点平均后噪声方差为 $\nu/J$，不把重复接收写成新的表面状态多样性。

| 前端与协议 | 导频 RE | 训练符号 | 表面切换 | 接收通道 |
|---|---:|---:|---:|---:|
| 数字，$J=1,K_p=128$ | 128 | 1 | 0 | 1280 |
| 数字，$J=8,K_p=16$ | 128 | 8 | 0 | 1280 |
| DMA，F1 $J=1,K_p=128$ | 128 | 1 | 0 | 8 |
| DMA，F2 $J=8,K_p=16$ | 128 | 8 | 7 | 8 |

数字接收是增加硬件通道后的控制，不是与 DMA 硬件等成本的竞争方案。两前端复用同一个宽带 DDPM：其离线先验训练不依赖观测前端，在线引导则分别在验证集选参。全局 LMMSE 统一先用 256 个训练场景；这是控制数字协方差内存的声明预算，不称为完整 2048 样本统计。三个训练种子与协方差样本数扫描待正式结果后安排。

## 7. 正式运行：步骤 2

每个配置为 4096/256/100 场景、一个 Clean DDPM、500 epochs、16000 次更新，验证与冻结测试各 10800 行。三者的路径几何与增益逐场景相同，载频/吸收按表改变；所有配置都依赖前述固定噪声参照数据。

```powershell
$py = 'D:/Program Files/Miniconda/envs/ris_td3/python.exe'
foreach ($factor in @('40ghz_noabs','300ghz_noabs','300ghz_abs')) {
    $cfg = "configs/zhou2025_carrier_${factor}.toml"
    $prefix = "zhou_carrier_${factor}_20261011"
    $dataId = "${prefix}_data_v1"
    $modelId = "${prefix}_clean_v1"
    $valId = "${prefix}_val_v1"
    $testId = "${prefix}_test_v1"

    & $py scripts/run_zhou2025_repro.py prepare --config $cfg --run-id $dataId
    if ($LASTEXITCODE -ne 0) { throw "carrier data failed: $factor" }
    & $py scripts/run_zhou2025_repro.py train --config $cfg --run-id $modelId --data-run-id $dataId
    if ($LASTEXITCODE -ne 0) { throw "carrier training failed: $factor" }
    & $py scripts/run_zhou2025_repro.py evaluate --config $cfg --run-id $valId --data-run-id $dataId --train-run-id $modelId --split validation
    if ($LASTEXITCODE -ne 0) { throw "carrier validation failed: $factor" }
    & $py scripts/run_zhou2025_repro.py evaluate --config $cfg --run-id $testId --data-run-id $dataId --train-run-id $modelId --split test --tuning-run-id $valId
    if ($LASTEXITCODE -ne 0) { throw "carrier test failed: $factor" }
}
```

相同场景与名义横轴的 `complex_noise_variance_phys` 必须跨三个配置一致；40/300 GHz 无吸收对照报告载频、实际接收功率与空间稀疏度差异，300 GHz 两配置对照单独报告吸收差异。若差异很小，记录效应量与区间，不调整距离或频段以制造结果。这个三点控制不构成全面的太赫兹频段扫描。

## 12. 数字接收与 DMA 的差别及诊断目的

2026-10-13 D-040 说明。本节解释已有实现与结果，没有启动第 11 节的新研究实验。两种前端复用同一个宽带信道和 Clean DDPM 权重；改变的是观测算子及其验证集冻结引导。

### 12.1 接收的信息不同

全数字接收逐阵元记录选中频点，单位导频下为

$$
z_{j,k,s,e}=h_{k,s,e}+n_{j,k,s,e}.
$$

DMA 每条微带合并 160 个阵元，再记录一个 RF 输出：

$$
y_{j,k,s}=\mathbf q_{j,k,s}^{\mathsf H}\mathbf h_{k,s}+v_{j,k,s}.
$$

权重包含既有 Lorentzian 和馈线频响。算子、噪声白化与空间 DFT 分别见 [wideband.py](../src/zhou2025_repro/wideband.py)、[dma.py](../src/zhou2025_repro/dma.py) 和 [data.py](../src/zhou2025_repro/data.py)。完整 CSI 有 $128\times8\times160=163840$ 个复数未知量。

| 前端与协议 | 接收通道数 | 原始复数观测数 | 不加路径结构时的观测秩上限 |
|---|---:|---:|---:|
| 数字，128 点、1 次 | 1280 | 163840 | 163840 |
| 数字，16 点、8 次 | 1280 | 163840 | 20480 |
| DMA F1，128 点、1 配置 | 8 | 1024 | 1024 |
| DMA F2，16 点、8 配置 | 8 | 1024 | 1024 |

数字全频点接收直接约束所有阵元 CSI，估计主要是去噪。数字 16 点重复提高这些频点的 SNR，但不增加频率覆盖。DMA 还丢失直接的阵元分辨信息；F1 的跨频权重或 F2 的多配置需要与共享路径结构共同作用，才可能补全完整 CSI。表中秩上限针对任意 CSI 线性空间，不能替代三径模型的可辨识性分析。

### 12.2 已有结果指向哪里

1. **数字全频点通过去噪，频率补全尚未通过。** 全频点 30 dB 的 DDPM 为 −32.291 dB；数字 16 点的导频误差 −38.935 dB，未观测频率却为 −0.899 dB。因此“数字结果良好”目前主要成立于完整观测。
2. **DMA 更依赖未观测部分的先验。** 两个固定案例的预测能量只有真值约 0.023%–0.029%，完整误差约 0 dB，观测残差仍可接近噪声。若误差落在观测零空间，降低观测残差不能消除这部分 CSI 误差。强人工噪声下的先验去噪也未通过，本轮没有将它隔离为唯一原因。
3. **实际接收 SNR 与名义横轴不同。** 30 dB 是训练平均单阵元输入参考；DMA 实际白化 SNR 为约 8.76/8.38 dB。投影方向与信道、合并噪声和频响共同决定该值；统一缩放权重会同时缩放信号及合并前噪声，不能把差值直接归为器件插入损耗。
4. **结构化恢复仍有空间。** 同观测下，真实几何 LS 可达约 −33 dB，已知粗中心 LMMSE 为 −17/−24 dB。这说明附加几何信息可支持更好的恢复；它不证明未知几何时已可辨识，也不构成同信息条件的算法排名。

当前判断是：压缩观测使恢复更依赖共享物理结构，而现有全局先验及在线引导尚未在这一条件下获得有效完整 CSI。压缩、噪声、规则选频、先验与引导的具体贡献仍须分离。

### 12.3 补强基线的目的

目的是得到可信的学习增益，排除有限统计样本或未收敛优化造成的比较偏差。全频点的 256 样本全局 LMMSE 在无噪声时仍为 −1.418 dB，其估计受训练样本张成空间限制；相对它的约 30.9 dB 优势不能代表相对可靠数字估计器的收益。采用同观测直接 LS 后，30 dB 的 DDPM 改善为约 2.39 dB。

扩大 LMMSE 样本数用于检验协方差近似和张成空间不足占多大比例，不保证更多样本一定消除地板。LASSO 固定惩罚只增加迭代，核对目标函数和误差，检验原预算对排名的影响，避免同时改变选参。上述扫描尚未执行。

### 12.4 固定权重观测诊断的目的

目的是确定下一步应改观测、先验还是在线恢复，避免同时换网络与协议后失去因果定位。

| 控制 | 要区分的问题 | 结果如何影响下一步 |
|---|---|---|
| 无噪声与带噪 | 噪声主导，还是结构/恢复地板 | 无噪声仍失败时，先检查结构和恢复；只在带噪失败时检查噪声模型、白化及正则 |
| 数字全频点与数字 16 点 | 去噪能力与跨频补全能力 | 已观测频点好而未观测频点差时，改进共享频率结构的利用 |
| 16 点规则与非规则选频 | 规则选频引起的相位歧义是否重要 | 固定资源后若非规则选频有效，再研究采集设计；未改善时继续检查先验和引导 |
| 数字与 DMA | 频率缺失与空间压缩各自的影响 | 同信道、同输入噪声下分开测量，保留硬件和信息数量差异 |
| 行空间与零空间误差 | 观测拟合失败，还是未观测信息恢复失败 | 行空间误差高时检查似然/引导；零空间误差高时检查结构先验与歧义 |
| 引导轨迹与真实几何控制 | 恢复在哪一阶段失稳；前向与增益拟合是否正确 | 跟踪 CSI 能量、分域误差和观测残差，定位失稳阶段；几何真值控制只验证有条件的链路 |

这组控制只在验证集设计与选参。先判断限制来自哪里，再决定是否修改模型或重训。两项建议仍未被本次代码归档任务自动采纳。Linux 运行和资料传输见 [Linux 指南](../docs/LINUX_RUN.md)。

## 13. D-041：关闭吸收的最小对照与接管状态

日期：2026-10-13。用户已确认这一排查方向。第13节保留初次确认时的设计与接管状态；同日的最小实现、小检查及 Linux 交付续记见第14节，正式匹配先验训练仍待用户执行。

### 13.1 要回答的问题与已有证据

要查明的是：原窄带MIMO中有效的DDPM，为什么在当前DMA观测下未恢复完整CSI；失败由DMA合并、宽带信道变化、二者交互，还是恢复实现和噪声处理导致。

原本地窄带MIMO的Clean DDPM/SURE-DM已通过D-038冻结测试。原文也包括不足导频的欠定恢复，因此不能把“观测有压缩”本身当作新发现。SURE通过对带噪训练CSI去噪来改善先验学习，不直接解决在线DMA观测缺少阵元信息的问题。[Zhou@2025，TWC](https://arxiv.org/abs/2408.10501v2)

D-039的宽带全频数字结果为−32.291 dB，直接LS为−29.901 dB；这组观测覆盖完整CSI，主要检查去噪与恢复链路。数字16点结果的导频域为−38.935 dB、未观测域为−0.899 dB，检查的是频率补全；它不是窄带系统。DMA全带约0 dB，两个已检查案例的输出能量仅约为真值的0.023%–0.029%，而观测残差仍接近噪声量级。现有证据尚未区分DMA、宽带与恢复过程各自的贡献，不能将约0 dB归因于某一因素。

分子吸收可计算，但随频率与路径长度变化，宽带多径下通常不是统一可除的常数。首轮直接关闭吸收，排除它的作用；后续是否恢复吸收根据诊断结果确定，不改写既有含吸收研究模型。[ITU-R@2022，P.676-13](https://www.itu.int/rec/R-REC-P.676-13-202208-I/en)

### 13.2 最小对照与执行顺序

沿用单发射端、8×160接收阵列，固定中心载频和米制阵元位置，按相同场景ID配对路径几何与复增益。四组均关闭吸收：

| 组别 | 信道与接收 | 具体检查 | 当前进度 |
|---|---|---|---|
| A | 同阵列窄带、全数字 | 固定一个物理频率，直接接收全部阵元，检查窄带数据与去噪链路 | 尚未建立；原64×16双端MIMO不能替代 |
| B | 同阵列窄带、DMA | 同A信道，经中心频率的DMA权重合并；先检查足够配置，再减少配置 | 优先补齐，尚未实施 |
| C | 同阵列宽带、全频数字 | 直接接收全128点全部阵元，检查匹配宽带先验和去噪 | 旧含吸收结果已完成；新的无吸收版本未运行 |
| D | 同阵列宽带、DMA | 同C信道与先验，经频变DMA算子恢复完整CSI | 旧含吸收结果约0 dB；新的无吸收版本未运行 |

先检查A/B的生成、尺度与观测链路，再开展C/D。首轮宽带对照使用全频观测来避免同时加入112个缺失频点；原F2和非规则选频留待主要失败环节定位后处理。具体配置数和资源预算在运行前声明，不把诊断控制当作等硬件、等成本的方案排名。

窄带先在一个固定物理频率计算信道与DMA响应。重复导频只提供重复测量或不同配置，不因复制频点获得新的跨频约束。现有评价接口按128点编写，单频形状和NMSE必须适配并检查，不能把16点宽带稀疏采样称作窄带。

### 13.3 固定条件、数据和训练

- **吸收关闭。** 复用物理生成器的 `include_absorption` 接口，生成新的信道与来源清单。既有宽带包装直接引用缓存，改包装配置不会改变旧缓存中的吸收。禁止编辑原表、旧清单、依赖哈希或缓存来绕过校验。
- **几何与硬件固定。** 窄/宽带使用配对路径几何、复增益、米制阵元位置和DMA可行调谐集合；保留球面传播、馈线传播及合并噪声位置。改变带宽时，分别记录信道频率变化和DMA权重频率变化。
- **先验匹配。** 两种带宽分别用无吸收、匹配分布的Clean CSI训练DDPM；同一带宽的数字/DMA共享训练数据和模型。尽量保持网络结构、扩散日程、训练更新预算及种子口径，并明确必须改变的输入形状。不能强行加载原双端MIMO权重，或把旧含吸收模型的分布变化当作宽带效应。
- **先无噪声、再带噪。** 无噪声组不添加观测噪声；若求解器要求正方差，预先声明并记录数值似然方差，并检查更小取值是否改变结论。带噪组按训练集平均白化观测功率匹配接收SNR，同时保存实际SNR、物理噪声与输入参考；不用评价真值逐场景重标定。这属于诊断对齐，等输入噪声的原物理结果保留。
- **配置先检查、再减少。** 窄带DMA不能默认只用一个配置。先检查观测矩阵的秩、奇异值和条件数，结合相同信息条件的恢复参照，确认所用信道族的可恢复范围，再减少配置。真实几何LS只检查前向、增益拟合与条件重构，不能证明未知几何可恢复。
- **选参分离。** 引导强度等只在验证集确定，数字与DMA分别冻结；测试只读取冻结结果。每组保存运行ID、解析配置、源码、数据/权重依赖和逐场景指标。具体样本数、配置数、训练预算及通过门槛在实施前固定。

### 13.4 观测指标与结果判别

至少保存完整阵元CSI NMSE、观测残差、预测能量/真值能量和归一化相关。沿DDPM恢复步骤保存同样的量，检查估计是在初始化、强噪声阶段或后期引导中缩到接近零。真值只用于评价，不能用于选择中间步骤或配置。

同时区分误差中会改变观测的部分与不会改变观测的部分：前者是观测行空间误差，后者是零空间误差。行空间误差高，优先检查算子、尺度、似然梯度与引导；观测已拟合但零空间误差高，说明缺失CSI尚未补回，还需区分先验能力与多个信道产生相近观测的歧义。

| 观察结果 | 支持的判断 | 后续检查 |
|---|---|---|
| A正常，B在无噪声、足够配置下失败 | DMA条件下已出现失败，尚不需要宽带来触发 | 核对前向/伴随/似然尺度；比较同信息恢复参照；检查先验与引导轨迹 |
| B只有在少配置下失败 | 配置减少触发信息不足或条件恶化 | 配置数与奇异值/结构区分性的关系；不直接判定DDPM算法无效 |
| A/B正常，C失败 | 新宽带数据、先验或去噪链路存在问题 | 检查跨频表示、训练/验证误差及扩散噪声各阶段的去噪能力 |
| B/C正常，D失败 | 宽带与DMA联合条件触发失败 | 固定宽带信道，将DMA权重冻结为中心频率响应作后续消融，再与真实频变权重比较 |
| 无噪声通过、带噪失败 | 噪声处理或噪声下的恢复能力成为重点 | 核对白化协方差、实际SNR、引导尺度及噪声敏感性 |

若相同信息条件的参照也失败，先研究观测是否足以区分合法信道；若只有读取真实几何的参照通过，仍不能排除未知几何的歧义。若同信息参照恢复而DDPM失败，再重点研究学习先验与后验恢复。结果只支持对应控制条件，不把条件恢复或小规模检查写成完整方法收益。

## 16. 冻结先验诊断与标量融合：前两步实施
