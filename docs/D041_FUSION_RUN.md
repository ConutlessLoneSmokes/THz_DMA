## 2. 第一步：定位先验、引导与噪声

`calibrate`对完整CSI施加人工VP噪声，再使用冻结网络预测噪声。每个VP步记录去噪误差、预测能量及相关性；验证集在t=100/75/50/25/10/5/1额外按五个算子分解行空间、零空间和已观测/未观测频率误差。完整CSI人工去噪使用额外真值信息，只诊断先验，不能作为实际DMA恢复方法。

`tune`在验证场景0–31上，将原Zhou分支的引导网格扩展为0.5/1/2/4/8/16。每个算子、每个噪声条件分别按最终端点的平均线性NMSE选参；任何非有限候选整体不参与选择，失败案例仍保存。最优值落在16时明确标记边界，不自动继续扩网格。

无噪声观测的物理噪声为0，似然计算分别用复数值方差1e−8和1e−10。带噪两组使用全部2048个训练场景的平均白化接收功率P，统一设复噪声方差为P/100；它与原训练RMS尺度一致，不按待评价样本真值改噪声。保存每场景理论实际SNR和噪声实现SNR，它们不必恰好20 dB。独立RE噪声来自配对公共配置—频率网格，再采集实际使用的RE；各方法使用同一观测。

最终端点、实际反向状态与网络输出的去噪均值分开记录。轨迹中的状态为`decode(z_t)/sqrt(alpha_bar_t)`，包含初态及每次更新；只有t=0进入最终评价和选参，不从轨迹挑最好一步。

## 3. 第二步：标量融合原型A1

冻结噪声网络得到VP去噪均值：

$$
r_t=\frac{z_t-\sqrt{1-\bar\alpha_t}\,\epsilon_\theta(z_t,t)}{\sqrt{\bar\alpha_t}}.
$$

前256个训练场景的人工VP去噪误差，在每个t上按实数坐标求平均平方误差，形成固定$v_t I$；下限1e−8。它是围绕当前去噪均值的平均二阶误差近似，既不是精确条件协方差，也不是新训练的协方差网络。验证结果不参与$v_t$标定。

在白化后的实数坐标，观测矩阵为A、噪声协方差为R，局部融合为：

$$
\widehat h_t=r_t+v_t A^{\mathsf T}(R+v_t AA^{\mathsf T})^{-1}(y-Ar_t).
$$

实现复用逐频SVD；对应复数协方差为$2v_tI$，复噪声方差为$\nu$时每个实部分量方差为$\nu/2$。随后把$\widehat h_t$代入标准DDPM后验均值的干净变量位置，执行确定性递推；不再叠加旧似然引导。两分支均使用现有100步、100次网络调用和相同初始随机状态。小维一般高斯控制只验证局部条件均值/协方差，不声称该有限确定性轨迹等于全局MMSE或精确后验采样。

单次标量融合只修改算子行空间；零空间补全仍依赖迭代中的网络先验。A1若无收益，不能推出学习结构化协方差一定无效，也不能推出低RE问题信息论上不可恢复。

## 4. 选参、筛选与判别

`screen`只读取已完成`calibrate`和`tune`的冻结清单，在验证场景32–95上评价选定的原DDPM、A1和同观测伪逆LS。该64场景是本次不重叠的验证筛选集，历史上已被其他实验使用，不能称新独立测试。当前不访问test真值执行评价。

| 观察到的结果 | 支持的下一判断 |
|---|---|
| 完整CSI人工去噪较好，DMA恢复很差 | 优先查观测融合、迭代状态偏移和欠定补全，不能只据此排除先验问题 |
| 扩展引导明显改善，尤其零空间误差下降 | 原引导上限可能限制结果；应以重调后的基线比较A1 |
| A1在相同观测/调用数下改善且两数值方差稳定 | 支持继续投入融合结构；仍需更强基线和独立测试 |
| 无噪声正常、20 dB明显退化 | 结合实际SNR、残差和均值/状态轨迹检查噪声处理及方差近似 |
| 压力点两方法仍约0 dB | 当前方法未补全，不能据此证明信息不足或不存在可恢复算法 |

筛选看CSI NMSE、≤−10 dB场景比例、逐场景方法差值及行/零空间误差。无噪声按每场景两数值方差较差值在线性域平均，另保留原0.1 dB敏感性标记。若A1在4096 RE获得约1 dB以上稳定改善、8192 RE没有明显回退，可作为后续工程投入的线索；这是预声明筛选建议，不是新颖性或可发表门槛，也不自动授权下一阶段训练。

正式三个阶段预期：训练/验证人工去噪25600/3200条；tune3072条最终指标，screen2304条，共5376条。DDPM反向轨迹在全部有限时为426624条。非有限结果计入失败分母，均值留空，保存失败原因，不删样本美化均值。
